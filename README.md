## ⚙️ Features
- **Tag all** group members with `.tagall`
- **Admin restricted** usage
- **Games** like Tic-Tac-Toe
- **Text-to-Speech** with `.tts`
- **Sticker creation** with `.sticker`
- **Anti-link detection**
- **Warn and manage** group members
